# Six Circle — sitio web oficial

Sitio estático (HTML + CSS + JS, sin compilación ni librerías externas) publicado con GitHub Pages en https://sixcircleoficialband.github.io/

- **Contenido** (biografía, integrantes, lanzamientos, videos, enlaces): `data/banda.js`
- **Noticias** (página Noticias y últimas 3 en el Inicio): `data/noticias.js`
- **Guía de edición paso a paso:** [EDITAR-WEB.txt](EDITAR-WEB.txt)
- Vista previa local: `python3 -m http.server 8000` → http://localhost:8000

Web hecha por [Ghatu Games](https://ghatugames.github.io).
